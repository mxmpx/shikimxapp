# Чеклист ручного прохода

Автоматика (axe + DOM-эвристики) закрывает ~40% дефектов. Остальное — здесь.
Иди по состояниям из `.audit/coverage.md`, на каждое — 1–2 минуты. Отмечай `✅ / ❌ / n/a`.

## 1. Первый экран и навигация

- [ ] Понятно за 5 секунд, что это за продукт и что делать дальше.
- [ ] Все пункты навигации работают, активный пункт визуально отличается не только цветом.
- [ ] Хлебные крошки / кнопка «назад» ведут туда, куда ожидает пользователь.
- [ ] Логотип ведёт на главную.
- [ ] Нет тупиков: с любой страницы можно уйти без браузерной кнопки «назад».
- [ ] Deep-link: перезагрузка страницы не теряет текущий раздел (для SPA — проверить обязательно).
- [ ] 404 и неизвестный маршрут оформлены, есть путь назад.

## 2. Доступность (a11y)

- [ ] Весь интерфейс проходится `Tab`; порядок фокуса совпадает с визуальным.
- [ ] Видимый focus-ring у всех интерактивных элементов (не `outline: none` без замены).
- [ ] Модалки: фокус внутрь, focus trap, `Esc` закрывает, фокус возвращается на триггер.
- [ ] Иконки-кнопки имеют доступное имя (`aria-label` / скрытый текст).
- [ ] Изображения: `alt` осмысленный или пустой для декоративных.
- [ ] Заголовки идут по уровням: один `h1`, без перескоков `h2 → h4`.
- [ ] Один `main`, навигация в `nav`, есть `skip-link`.
- [ ] Контраст текста ≥ 4.5:1 (крупный ≥ 3:1), иконок ≥ 3:1, границ полей ≥ 3:1.
- [ ] Смысл не передаётся только цветом (ошибки, статусы, графики).
- [ ] `prefers-reduced-motion`: анимации (у проекта есть `MorphingCursor` и `reveal-pop`) отключаются.
- [ ] Работает при масштабе 200% и `font-size` 24px — ничего не обрезается.
- [ ] Формы: `label` связан с полем, ошибка рядом с полем, `aria-invalid`, `aria-describedby`.
- [ ] Автозаполнение/менеджер паролей не ломает вёрстку полей.
- [ ] Скринридер: осмысленные названия кнопок («Закрыть», а не «✕»).

## 3. Состояния данных

Проверь каждое для списков, карточек, таблиц:

- [ ] Загрузка (скелетон/спиннер) — и он не «прыгает» по высоте.
- [ ] Пусто (0 результатов) — объяснение + действие («Сбросить фильтры»).
- [ ] Ошибка сети — текст, повтор запроса, не пустой экран.
- [ ] Частичная ошибка (одна картинка не загрузилась) — плейсхолдер.
- [ ] Очень много данных (100+) — пагинация/бесконечный скролл не ломается.
- [ ] Долгие строки: название 200 символов, эмодзи, HTML-спецсимволы.
- [ ] Нет «undefined», «null», «NaN», «[object Object]», `0` вместо пустоты.
- [ ] Нет двойных пробелов, точек в заголовках, разнобоя «ё/е».

## 4. Адаптивность

- [ ] 320 / 390 / 768 / 1024 / 1440 / 1920 — без горизонтального скролла.
- [ ] Мобильный: ничего не перекрыто фиксированным `BottomNav` (последний элемент списка достижим).
- [ ] `100vh` в модалках не уезжает под адресную строку (использовать `100dvh`).
- [ ] Тач-таргеты ≥ 44×44 и ≥ 8px между ними.
- [ ] Клавиатура на мобиле не закрывает поле ввода и кнопку отправки.
- [ ] Ландшафт на телефоне (844×390) — модалки/меню не обрезаны.
- [ ] Таблицы на мобиле: скролл внутри контейнера, а не всей страницей.
- [ ] Текст читается без зума (≥ 16px для основного).

## 5. Интерактив

- [ ] Для каждой кнопки: default / hover / active / focus / disabled / loading.
- [ ] Двойной клик не отправляет форму дважды; кнопка блокируется на время запроса.
- [ ] Деструктивные действия спрашивают подтверждение или имеют undo.
- [ ] `Esc` и клик вне закрывают дропдауны/модалки/шиты.
- [ ] Дропдаун не вылезает за экран у правого/нижнего края.
- [ ] Скролл фона блокируется, когда открыта модалка (но сама модалка скроллится).
- [ ] Ссылки выглядят как ссылки, кнопки — как кнопки; нет `div` с `onClick` без роли.
- [ ] Hover-эффекты не «прыгают» (меняется только цвет/тень, не размер).

## 6. Формы и валидация

- [ ] Валидация появляется после взаимодействия, а не сразу при загрузке.
- [ ] Ошибка объясняет, что исправить, и не стирает введённое.
- [ ] Обязательные поля помечены и озвучиваются скринридером.
- [ ] Enter отправляет, Shift+Enter переносит строку в textarea.
- [ ] Плейсхолдер не заменяет label.
- [ ] Числовые поля: вставка `12abc`, минус, огромные числа не ломают приложение.

## 7. Производительность и восприятие

- [ ] Нет layout shift при загрузке картинок (заданы `width/height` или `aspect-ratio`).
- [ ] Анимации не блокируют ввод; курсор/оверлеи не мешают кликам.
- [ ] Нет мигания темы при старте (FOUC / неправильная тема на первом кадре).
- [ ] Долгие операции показывают прогресс, а не «зависло».
- [ ] Список из 100 карточек скроллится плавно (при лагах — виртуализация).
- [ ] Нет утечек: после 10 переходов по табам память и слушатели не растут.

## 8. Контент и микрокопия

- [ ] Термины едины («Тайтл» vs «Аниме» vs «Сериал» — выбрать одно).
- [ ] Кнопки: глагол + объект («Добавить в список», не «ОК»).
- [ ] Ошибки без обвинений и без технического жаргона.
- [ ] Даты/числа/разделители в одном формате и локали.
- [ ] Плюрализация: 1 тайтл / 2 тайтла / 5 тайтлов.
- [ ] Русский/английский не смешаны в одном предложении без причины.

## 9. Тема (у проекта есть тёмная/светлая)

- [ ] Обе темы: контраст, границы, тени, изображения.
- [ ] Переключение не требует перезагрузки и сохраняется.
- [ ] Прозрачные/блюр-поверхности читаемы на светлом фоне.
- [ ] Нет «белых вспышек» у модалок в тёмной теме.

## 10. Глобальное

- [ ] Ни одной ошибки в консоли и ни одного 4xx/5xx на нормальном сценарии.
- [ ] `favicon`, `<title>`, `meta description`, OG-изображение на месте.
- [ ] Никаких `TODO`, `lorem ipsum`, тестовых данных и «Иван Иванов».
- [ ] Работает с выключенным интернетом после загрузки: понятный оффлайн-экран.
