## 🌟 О проекте

**Shiki MX App** — это быстрый, адаптивный и эргономичный веб-клиент для платформы [Shikimori](https://shikimori.one). Приложение совмещает функции персонального кабинета, полноценного каталога с фильтрами, расписания онгоингов, прямого редактирования пользовательских списков и встроенного онлайн-просмотра аниме через мультипровайдерный видеоагрегатор.

Архитектура построена на модульных blueprint'ах **Flask**, использует встроенный **GraphQL-клиент** для быстрой пакетной загрузки постеров, локальную базу данных **SQLite** для сохранения пользовательских настроек, а также **Service Worker (PWA)** для оффлайн-доступа и установки на ПК и смартфоны.

## 🚀 Основные возможности

- 🔒 **Авторизация Shikimori OAuth 2.0:** Безопасный вход с чтением и записью данных пользователя.
- 📺 **Онлайн-просмотр аниме (Мультипровайдерный агрегатор):**
  - Пошаговый эргономичный мастер выбора (Wizard UI: Серии -> Озвучки -> Источники).
  - Автоматическая нормализация и объединение одинаковых озвучек из разных парсеров (Kodik, AnimeGo, YummyAnime, AniLibria) с нумерацией зеркал (`Kodik #1`, `Kodik #2`).
  - Умное переключение серий (`След. серия` / `Пред. серия`) с автоматическим сохранением выбранной озвучки и источника.
  - Настоящий системный **Document Picture-in-Picture (PiP)** (Always-On-Top окно поверх всех приложений и игр при свёрнутом браузере).
  - Быстрые действия под окном плеера (Пред. серия, +85 сек, След. серия, PiP).
  - Виджет **«Продолжить просмотр»** с сохранением истории прогресса по сериям и таймкодов.
- 📝 **Интерактивное управление списками («Мой список»):**
  - Добавление, изменение статусов (Смотрю, Просмотрено, В планах, Брошено и др.).
  - Быстрый инкремент серий (`+1`) на карточках и в модальном окне.
  - Выставление оценок (1–10 золотых звезд), текстовые заметки и удаление из списков (Shikimori User Rates API v2).
- 📅 **Расписание онгоингов (Календарь):**
  - Группировка релизов по дням недели с бейджами времени выхода и рейтинга.
- 🗂️ **Расширенный Каталог аниме:**
  - Фильтры по жанрам, сезонам, годам выхода, типам (TV, Movie, OVA, ONA, Special), статусам и минимальной оценке.
  - Сортировка по рейтингу, популярности, дате и названию.
- 🎲 **Рандомайзер аниме («Мне повезёт!»):**
  - Моментальный подбор случайного аниме под настроение.
- 🖼️ **Галерея скриншотов & Fullscreen Lightbox:**
  - Загрузка полной коллекции кадров (30–50+ скриншотов из Shikimori API).
  - Полноэкранный просмотрщик с зумом и поддержкой клавиш навигации (`Esc`, `←`, `→`).
- 🪟 **Полноэкранные модальные окна (100vw × 100vh):**
  - Двухколоночный эргономичный интерфейс: слева фиксированный постер, кнопки плеера и виджет списка; справа заголовок, видеоплеер, блок характеристик, описание, персонажи с сейю, скриншоты, франшиза и трейлеры.
  - Полноэкранные окна для Аниме, Манги, Настроек и раздела «О сайте».
- 📱 **Премиум мобильный интерфейс и навигация:**
  - **Списки и Избранное в 3 колонки:** Компактная сетка постеров на глубоком чёрном фоне (`#000000`) со скруглением `22px`, горизонтальными подчёркнутыми табами статусов (`#e5a543`), переключателем `[ Аниме | Манга ]` и моментальным поиском.
  - **История просмотров по макету:** Детальные горизонтальные карточки с постерами `88px`, номерами серий, студиями озвучки (`WinMedia`, `Crunchyroll.Subtitles`), статусом просмотра и прошедшим временем (`6 часов назад` / `28 авг., 17:21`).
  - **Пакетное GraphQL-обогащение постеров:** Полное отсутствие битых заглушек `missing_original` благодаря автоматической пакетной подгрузке WebP-постеров из GraphQL Shikimori и асинхронному фоллбэку.
  - **Мобильные экраны Персонажей и Манги:** Адаптивные карточки с кнопкой «Поделиться» (копирование ссылки в буфер), ролями, характеристиками, томами и главами.
  - **Умная навигация AppNav:** Глубокий стек истории переходов («Назад», системный жест, `Esc`) между связанными аниме, мангой, персонажами и вкладками без случайного закрытия приложения.
  - **Консольная пасхалка (Mobile):** Стилизованный OneDark терминал со скользящей анимацией легендарных аниме-фраз на моноширинном шрифте **JetBrains Mono**.
  - **Интерактивный экран загрузки (Desktop):** Сенсорная сетка из вращающихся `+` символов в фирменной палитре Shiki MX с реакцией на курсор мыши.
- 📱 **PWA (Progressive Web App):**
  - Возможность установки как нативного приложения на Windows, macOS, Android и iOS.
  - Автоматическая сборка бандлов (`bundle.css`, `bundle.js`) и динамическое хэш-версионирование кэша Service Worker при старте `app.py`.
- ⚡ **Оптимизация производительности (60fps):**
  - Использование `content-visibility: auto` и `contain-intrinsic-size` для карточек.
  - Асинхронное декодирование картинок (`decoding="async"`, `loading="lazy"`).
  - Дисковое кэширование изображений и TTL-кэширование API запросов с защитой от rate-limit 429.
- 🎨 **Кастомизация и синхронизация настроек:**
  - Выбор цвета фона или загрузка собственного изображения.
  - Настройка отображения навбара (иконки + названия, только иконки, только названия) с сохранением в БД SQLite.
  - Управление видимостью блоков на главной странице.
- 🌐 **Двуязычная локализация:**
  - Полная поддержка интерфейса на русском (RU) и английском (EN) языках.

## 💾 База данных

Приложение использует SQLite (`app.db`) со следующими таблицами:

### `users`
- `id` — внутренний идентификатор
- `shikimori_id` — ID пользователя на Shikimori (уникальный)
- `email`, `name`, `avatar` — профильные данные
- `access_token` — токен доступа Shikimori API

### `user_settings`
- `user_id` — внешний ключ пользователя
- `key` — ключ настройки (`background`, `navbar_view`, `section_visibility`)
- `value` — сериализованные параметры в JSON

## 📡 Основные API Endpoints

| Endpoint | Метод | Описание |
|---|---|---|
| `/login` | GET | Перенаправление на авторизацию Shikimori OAuth |
| `/auth/callback` | GET | Обработка OAuth callback |
| `/logout` | GET | Завершение сессии |
| `/api/auth/status` | GET | Проверка текущего статуса авторизации |
| `/api/anime/<id>` | GET | Полная информация об аниме (с персонажами, скриншотами и франшизой) |
| `/api/anime/<id>/stream` | GET | Поиск потоков видео и серий через anicli/kodik |
| `/api/rate` | POST | Добавление / обновление аниме или манги в списке пользователя |
| `/api/rate/<id>` | PATCH/DELETE | Редактирование / удаление элемента из списка |
| `/api/rate/increment/<id>` | POST | Быстрое увеличение просмотренной серии на `+1` |
| `/api/calendar` | GET | Расписание выхода серий онгоингов по дням недели |
| `/api/catalog` | GET | Каталог аниме с фильтрами, поиском и пагинацией |
| `/api/random` | GET | Получение случайного аниме под заданные критерии |
| `/api/tab/explore` | GET | Новости и популярные темы дня с Shikimori |
| `/api/tab/rates` | GET | Списки пользователя (аниме и манга по категориям) |
| `/api/tab/friends` | GET | Друзья и клубы пользователя |
| `/api/tab/history` | GET | История просмотров и активности |
| `/api/tab/favourites` | GET | Избранные аниме, манга и персонажи |
| `/api/settings` | GET / POST | Чтение и сохранение пользовательских настроек |
| `/api/about` | GET | Информация о приложении и чейнджлог |

## ⚙️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/mxmpx/shikimxapp.git
cd shikimxapp
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневой папке проекта:
```env
FLASK_SECRET_KEY=your-secure-secret-key
SHIKIMORI_CLIENT_ID=your-shikimori-client-id
SHIKIMORI_CLIENT_SECRET=your-shikimori-client-secret
REDIRECT_URI=http://127.0.0.1:5000/auth/callback
DISABLE_CUSTOM_LOGGING=false
```

> **Примечание:** Получить `SHIKIMORI_CLIENT_ID` и `SHIKIMORI_CLIENT_SECRET` можно в [настройках профиля Shikimori (OAuth)](https://shikimori.one/oauth/applications).

### 4. Запуск приложения
```bash
python run.py
```
Приложение откроется по адресу: **`http://127.0.0.1:5000`**
