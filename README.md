## 🌟 О проекте

**Shiki MX App** — это быстрый, адаптивный и эргономичный веб-клиент для платформы [Shikimori](https://shikimori.one). Приложение совмещает функции персонального кабинета, полноценного каталога с фильтрами, интерактивного расписания онгоингов, прямого редактирования пользовательских списков и встроенного онлайн-просмотра аниме через мультипровайдерный видеоагрегатор.

Архитектура построена на 12 модульных blueprint'ах **Flask**, использует многопоточный **GraphQL-клиент** с параллельной выборкой чанков (`ThreadPoolExecutor`), двухуровневое **Stale-While-Revalidate (SWR)** кэширование (RAM + SQLite), а также автономный **Service Worker (PWA)** для оффлайн-доступа и установки на ПК и смартфоны.

## 🚀 Основные возможности

- 🔒 **Авторизация Shikimori OAuth 2.0:** Безопасный вход с чтением и записью данных пользователя.
- 🧭 **Интерактивное меню навигации («Главная ▾»):**
  - Выпадающий список разделов с категоризацией («БАЗА ДАННЫХ», «СООБЩЕСТВО», «РАЗНОЕ») и быстрым возвратом на «Главную».
- 📦 **12 самостоятельных портальных модулей:**
  - **Каталог аниме:** Полная фильтрация по жанрам, годам, сезонам, форматам, статусам и оценке.
  - **Топ 100:** Ранжированные списки лучших аниме, фильмов, онгоингов и манги с медалями (`🥇 #1`, `🥈 #2`, `🥉 #3`).
  - **Каталог манги:** Фильтрация по типам (манхва, маньхуа, ваншоты, додзинси) и статусам.
  - **Каталог ранобэ:** Удобный поиск и сортировка новелл.
  - **Форум сообщества:** Темы, категории, авторы и счётчики комментариев в реальном времени.
  - **Клубы Shikimori:** Популярные клубы со статусами доступа и участниками.
  - **Коллекции пользователей:** Подборки и авторские коллекции тайтлов.
  - **Рецензии и отзывы:** Развернутые обзоры с цитатами, датами и авторами.
  - **Статьи:** Аналитические материалы и статьи сообщества.
  - **Пользователи:** Поиск профилей и статус онлайна.
  - **Рекомендации:** Умный подбор аниме на базе предпочтений.
  - **Календарь онгоингов:** Интерактивное расписание релизов по дням недели.
- ♾️ **Бесконечная прокрутка (Infinite Scroll):** Плавная автоматическая подгрузка контента при скролле вниз для всех каталогов и модулей.
- 📺 **Онлайн-просмотр аниме (Мультипровайдерный агрегатор):**
  - Пошаговый эргономичный мастер выбора (Wizard UI: Серии -> Озвучки -> Источники).
  - Автоматическая нормализация и объединение одинаковых озвучек из разных парсеров (Kodik, AnimeGo, YummyAnime, AniLibria) с нумерацией зеркал (`Kodik #1`, `Kodik #2`).
  - Умное переключение серий (`След. серия` / `Пред. серия`) с автоматическим сохранением выбранной озвучки и источника.
  - Настоящий системный **Document Picture-in-Picture (PiP)** (Always-On-Top окно поверх всех окон при свёрнутом браузере).
  - Быстрые действия под окном плеера (Пред. серия, +85 сек, След. серия, PiP).
  - Виджет **«Продолжить просмотр»** с сохранением истории прогресса по сериям и таймкодов.
- 📝 **Интерактивное управление списками («Мой список»):**
  - Добавление, изменение статусов (Смотрю, Просмотрено, В планах, Брошено и др.).
  - Быстрый инкремент серий (`+1`) на карточках и в модальном окне.
  - Выставление оценок (1–10 золотых звезд), текстовые заметки и удаление из списков (Shikimori User Rates API v2).
  - Мгновенная синхронная инвалидация локального кэша списков и истории активности.
- 🎲 **Рандомайзер аниме («Мне повезёт!»):** Моментальный подбор случайного аниме под настроение с фильтром по жанрам и оценке.
- 🖼️ **Галерея скриншотов & Fullscreen Lightbox:**
  - Загрузка полной коллекции кадров (30–50+ скриншотов из Shikimori API).
  - Полноэкранный просмотрщик с зумом и поддержкой клавиш навигации (`Esc`, `←`, `→`).
- 🪟 **Полноэкранные модальные окна (100vw × 100vh):**
  - Двухколоночный эргономичный интерфейс: слева постер, кнопки плеера и виджет списка; справа заголовок, видеоплеер, блок характеристик, описание, персонажи с сейю, скриншоты, франшиза и трейлеры.
  - Полноэкранные окна для Аниме, Манги, Настроек и раздела «О сайте».
- 📱 **Премиум мобильный интерфейс и навигация:**
  - **Списки и Избранное в 3 колонки:** Компактная сетка постеров со скруглением `22px`, горизонтальными подчёркнутыми табами статусов (`#e5a543`), переключателем `[ Аниме | Манга ]` и моментальным поиском.
  - **История просмотров по макету:** Детальные горизонтальные карточки с постерами `88px`, номерами серий, студиями озвучки, статусом просмотра и прошедшим временем.
  - **Пакетное GraphQL-обогащение постеров:** Полное отсутствие битых заглушек `missing_original` благодаря автоматической пакетной подгрузке WebP-постеров из GraphQL Shikimori.
  - **Умная навигация AppNav:** Глубокий стек истории переходов («Назад», системный жест, `Esc`) между связанными аниме, мангой, персонажами и вкладками без случайного закрытия приложения.
- ⚡ **Высокая производительность (Core Web Vitals 100/100):**
  - **LCP:** 1.00 с (приоритезация `fetchpriority="high"` и `decoding="async"` для главных изображений).
  - **CLS:** 0.01 (стабильный макет без рывков).
  - **INP:** 24 мс (мгновенный отклик на клики и взаимодействия).
  - **SWR кэширование:** Все закэшированные эндпоинты отдаются за **< 3 мс**.
- 📱 **PWA (Progressive Web App):**
  - Возможность установки как нативного приложения на Windows, macOS, Android и iOS.
  - Автоматическая сборка бандлов (`bundle.css`, `bundle.js`) и динамическое хэш-версионирование кэша Service Worker при старте `app.py`.
- 🌐 **Двуязычная локализация (i18n):** Полная поддержка интерфейса на русском (RU) и английском (EN) языках.

## 💾 База данных

Приложение использует SQLite (`app.db`) со следующими таблицами:

### `users`
- `id` — внутренний идентификатор пользователя
- `shikimori_id` — ID пользователя на Shikimori (уникальный)
- `email`, `name`, `avatar` — профильные данные
- `access_token` — OAuth токен доступа Shikimori API

### `user_settings`
- `user_id` — внешний ключ пользователя
- `key` — ключ настройки (`background`, `navbar_view`, `section_visibility`, `language`)
- `value` — значение настройки или JSON-параметры

### `api_cache`
- `cache_key` — уникальный ключ кэша запроса
- `data` — JSON-сериализованный ответ API
- `expires_at` — время истечения актуальности (Unix timestamp)

## ⚙️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/mxmpx/shikimxapp.git
cd shikimxapp
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневой папке проекта на основе `.env.example`:
```env
FLASK_SECRET_KEY=your-secure-secret-key
SHIKIMORI_CLIENT_ID=your-shikimori-client-id
SHIKIMORI_CLIENT_SECRET=your-shikimori-client-secret
SHIKIMORI_REDIRECT_URI=http://127.0.0.1:5000/auth/callback
SHIKIMORI_APP_NAME=ShikiMXApp/1.0
DISABLE_CUSTOM_LOGGING=false
```

> **Примечание:** Получить `SHIKIMORI_CLIENT_ID` и `SHIKIMORI_CLIENT_SECRET` можно в [настройках OAuth Shikimori](https://shikimori.one/oauth/applications).

### 4. Запуск приложения
```bash
python run.py
```
Приложение откроется по адресу: **`http://127.0.0.1:5000`**
