# Shiki MX App

> Современное веб-приложение для удобного просмотра профиля, списков аниме и манги, новостей и онлайн-просмотра на базе API Shikimori.

## О проекте

**Shiki MX App** — это современный веб-интерфейс для платформы [Shikimori](https://shikimori.one), объединяющий функционал просмотра профиля, управления списками аниме и манги, новостной ленты и встроенного онлайн-просмотра аниме.

Приложение построено на архитектуре Flask с модульной структурой blueprint'ов и использует SQLite для хранения пользовательских данных и настроек.

## Возможности

- Интеграция с Shikimori через OAuth 2.0
- Авторизация через Google OAuth 2.0
- База данных SQLite для хранения пользователей и настроек
- Синхронизация настроек пользователя между устройствами (фон, видимость разделов)
- Быстрое встроенное кеширование данных и прокси картинок
- Поиск аниме и онлайн-просмотр видеоплееров (Kodik, Sibnet)
- Полная статистика профиля, список друзей, история и избранное
- Адаптивный дизайн с поддержкой тёмной и светлой тем

## Технологический стек

- **Python 3** — основной язык разработки
- **Flask** — веб-фреймворк
- **Shikimori REST API** — источник данных об аниме и манге
- **Anicli-API** — агрегатор видеопотоков
- **Vanilla JS** — клиентская логика без фреймворков
- **HTML5 / CSS3** — разметка и стили
- **Google Sans** — фирменный шрифт
- **SQLite** — база данных пользователей и настроек

## База данных

Приложение использует локальную SQLite базу данных (`app.db`) с двумя основными таблицами:

### `users`
Хранит информацию о авторизованных пользователях:
- `id` — внутренний идентификатор
- `shikimori_id` — ID на Shikimori (уникальный)
- `google_id` — ID Google аккаунта (уникальный)
- `email`, `name`, `avatar` — профильные данные
- `access_token` — токен доступа Shikimori API

### `user_settings`
Хранит пользовательские настройки в формате ключ-значение:
- Настройка фона (тема, цвет, изображение)
- Видимость разделов интерфейса

Пользователь автоматически создаётся в БД при первой авторизации через Shikimori или Google.

## API endpoints

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/login` | GET | Перенаправление на OAuth Shikimori |
| `/auth/callback` | GET | Обработка callback от Shikimori |
| `/logout` | GET | Выход из аккаунта |
| `/api/settings` | GET | Получение настроек пользователя |
| `/api/settings` | POST | Сохранение настроек пользователя |
| `/api/auth/status` | GET | Проверка статуса авторизации |

## Установка и запуск

### Требования
- Python 3.8+
- pip

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
FLASK_SECRET_KEY=your-secret-key
SHIKIMORI_CLIENT_ID=your-client-id
SHIKIMORI_CLIENT_SECRET=your-client-secret
REDIRECT_URI=http://127.0.0.1:5000/auth/callback
DISABLE_CUSTOM_LOGGING=false
```

### Запуск приложения

```bash
python run.py
```

Приложение будет доступно по адресу `http://127.0.0.1:5000`

## Онлайн-просмотр

Для поиска и просмотра аниме приложение использует многопоточный агрегатор видеопотоков на базе [anicli-api](https://github.com/vypivshiy/anicli-api) с поддержкой:
- AnimeGo
- YummyAnime
- AniLibria

А также прямого Kodik API с интеллектуальным алгоритмом сопоставления названий (Fuzzy Matching) и сезонов аниме.
